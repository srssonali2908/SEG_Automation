# Introduction

This guide explains how to install and configure the product.

## Overview

Welcome to Smoke Suite. It supports the following flows:

- Standalone use with `--standalone`
- Integrated use, where **both** tools share one *project*
    - Shared settings
    - Shared **Device** selection

Pass `<project_name>` to the tool, and set the clock to `C:\Quartus\bin`. The literal token `<signal_name>` appears here outside code.

To begin, see [Installing the Software](getting-started/installing-the-software/installing-the-software.md), then [follow the checklist](getting-started/installing-the-software/installing-the-software.md).
