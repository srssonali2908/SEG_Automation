# Troubleshooting the Installation

Common problems and fixes:

**Installer errors**

| Error | Fix |
| --- | --- |
| `E_PERM` | Re-run as administrator. |
| Disk full \| quota | Free space, then retry.<br>**Note:** Needs 4 GB. |

> [!WARNING]
> Do not interrupt the installer while it is writing files.

Missing target: `does-not-exist.dita` and a missing image [Image not found: missing].
